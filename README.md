# Проект "Магазин"

## Описание
Проект представляет собой систему для управления товарами в магазине с возможностью категоризации продуктов.

## Функциональность
- Создание продуктов с различными характеристиками
- Категоризация товаров
- Подсчет количества категорий и продуктов
- Абстрактный базовый класс для всех продуктов
- Класс-миксин для логирования создания объектов
- Специализированные классы для смартфонов и газонной травы

## Установка
1. Клонировать репозиторий
2. Установить зависимости: `pip install -r requirements.txt`
